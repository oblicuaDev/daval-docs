# Panel del administrador

## El menú

| Grupo | Opción | Para qué |
|---|---|---|
| — | **Inicio** | Dashboard con los indicadores del negocio |
| **Operaciones** | **Rutas** | Días de entrega y hora de corte |
| | **Empresas** | Empresas cliente, sus sucursales, ruta y asesor |
| | **Usuarios** | Cuentas de acceso de los clientes |
| | **Cotizaciones** | Todas las cotizaciones y su envío a SIIGO |
| | **Asesores** | Asesores comerciales y su vendedor en SIIGO |
| **Catálogo** | **Categorías** | Tipos de producto |
| | **Productos** | Catálogo, fotos, precios base y stock |
| | **Listas de precios** | Precios especiales por grupo de clientes |
| | **Promociones** | Precios temporales o permanentes |
| **Sistema** | **Integraciones** | Conexión con SIIGO y sincronización de productos |
| | **Clientes SIIGO** | Importar y exportar empresas con SIIGO |

## Dashboard (Inicio)

*Resumen general del sistema comercial.*

- **Indicadores:** total de cotizaciones, sincronizadas en SIIGO, **pendientes SIIGO**, total de productos y de clientes activos.
- **Top 10 Productos** por ingresos (con botón **Exportar CSV**).
- **Top 10 Clientes más activos** por ingresos.
- **Cotizaciones Recientes.**
- **Histórico de Consumos:** monto por mes de los últimos 12 meses.

Filtra con **Desde** / **Hasta**. Las cotizaciones rechazadas no suman en los ingresos.

:::tip[Revisión diaria]
El indicador **Pendientes SIIGO** te dice cuántas cotizaciones faltan por registrar en contabilidad. Púlsalo para ir directo a esa lista.
:::

## Puesta en marcha: orden recomendado

Si estás configurando la plataforma desde cero:

1. **Integraciones:** conecta SIIGO y sincroniza productos. Ver [Integración con SIIGO](./siigo.md).
2. **Categorías** y ajustes de **Productos** (fotos, calidad, categoría).
3. **Listas de precios** y **Promociones**.
4. **Asesores**, con su vendedor SIIGO.
5. **Rutas.**
6. **Empresas** con sus sucursales (asigna ruta y asesor), o impórtalas desde **Clientes SIIGO**.
7. **Usuarios** cliente, con su lista de precios.
