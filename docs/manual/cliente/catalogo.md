# Catálogo y carrito

## Buscar productos

En **Catálogo** puedes encontrar productos de varias formas:

- **Buscador** (arriba): escribe el nombre o el código (SKU) del producto.
- **Pestañas:** **Catálogo** muestra todo; **Promociones** muestra solo los productos con precio especial vigente.
- **Categorías:** filtra por tipo de producto (**Todos** para quitar el filtro).
- **Calidad:** filtra por *Calidad estándar*, *Alta calidad* o *Calidad premium*.
- **Vista:** cambia entre **cuadrícula** (con fotos) y **lista** (más compacta, útil para pedidos grandes) con los íconos de la derecha.

## Lo que ves en cada producto

| Elemento | Qué significa |
|---|---|
| Precio | **Tu precio**, según tu lista de precios. Ya incluye cualquier promoción vigente. |
| Etiqueta **Promo** | El producto tiene un precio promocional activo para ti. |
| Etiqueta **Pocas unidades** | Quedan menos de 20 unidades disponibles. |
| Unidad | Cómo se vende: unidad, caja, rollo, etc. |

:::info[¿Por qué mi precio es distinto al de otro cliente?]
Cada cliente tiene una lista de precios asignada por DAVAL, y algunas promociones son solo para ciertos clientes. Lo que ves siempre es tu precio real.
:::

## Agregar al carrito

1. Escribe la **cantidad** en la casilla del producto (mínimo 1).
2. Pulsa **Agregar**.

Si agregas un producto que ya estaba en el carrito, la cantidad se suma.

## El carrito

Pulsa el ícono del **carrito** (arriba a la derecha). Se abre un panel lateral con:

- Cada producto, su cantidad y su subtotal. Puedes cambiar cantidades o eliminar productos con el ícono de papelera.
- El **Total estimado**.
- El botón **Revisar y confirmar cotización**.

:::tip[Tu carrito se guarda]
Si cierras el navegador, el carrito sigue ahí cuando vuelvas (en el mismo computador o celular).
:::

:::note[Total estimado]
El total del carrito es una estimación. Al confirmar, la plataforma toma los **precios vigentes en ese momento**, por si alguna promoción empezó o terminó mientras armabas el pedido.
:::
